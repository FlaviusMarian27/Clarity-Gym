The web application, provisionally called Clarity Gym, is a platform
modern digital dedicated to the efficient management of the activity in a fitness room and the 
direct interconnection between clients and personal trainers.

The project is a significant architectural development of a concept
anterior. The main motivation is the transition from a technological stack of
base (HTML/JS/Node.js/MongoDB) on robust, oriented architecture
towards performance, using Go (Golang) for fast processing on
backend, React.js for a fluid interface and PostgreSQL for
ensuring the integrity of relational data.
